# Premium Fullstack Engineering

## Mission
Develop maintainable, secure, scalable and polished software
while preserving the existing project's architecture and requirements.

## Phase 1: Understand
- Identify the exact feature or problem.
- Read relevant requirements and source files.
- Identify existing patterns, dependencies and constraints.
- State assumptions instead of silently inventing requirements.

## Phase 2: Design
- Choose the simplest architecture that fulfills the requirements.
- Separate frontend, backend and data concerns appropriately.
- Define interfaces and data flow before complex implementation.
- Consider security, accessibility, performance and maintainability.

## Phase 3: Implement
- Follow existing project conventions.
- Build reusable components and modular functions.
- Validate inputs and handle error states.
- Avoid unnecessary dependencies and unrelated rewrites.
- Preserve backward compatibility when applicable.

## Phase 4: Verify
- Run available relevant tests, linting or type checks.
- Inspect edge cases and loading/error states.
- Identify potential security or performance problems.
- Clearly report anything that could not be verified.

## UI/UX
When working on interfaces:
- Use UI UX Pro Max if available.
- Respect approved Figma references.
- Establish visual hierarchy and consistent design tokens.
- Consider responsive behavior and accessibility.
- Aim for distinctive, premium product quality.

## Token Budget
- Read only necessary files.
- Avoid repeatedly loading unchanged context.
- Break complex tasks into manageable milestones.
- Keep explanations concise without sacrificing correctness.

## Required Delivery
Summarize:
- Implemented work
- Modified files
- Verification results
- Remaining risks or follow-up tasks
